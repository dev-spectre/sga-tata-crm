4. Pass `category` to `/api/leads` fetch parameters.
5. Create modern, responsive `.lead-category-tabs` CSS styles in `src/app/globals.css`.
6. Render the category switcher tab bar directly above the leads table in desktop view and mobile card view.
7. Verify with `npx tsc --noEmit`.
