# Phase 11 Plan 02: Automated Verification of Lead Category Queries and Stats

**Phase:** 11-backend-lead-categorization-pipeline-category-query-api
**Plan:** 11-02
**Status:** Pending
**Requirements Addressed:** LEAD-CAT-01, LEAD-CAT-02

## Objectives
1. Create and execute test script `scratch/verify-lead-categories.ts`.
2. Seed test leads representing each scenario:
   - Lead A: Inside Tamil Nadu + follow-up date today (Priority & Valid).
   - Lead B: Inside Tamil Nadu + follow-up date overdue (Priority & Valid).
   - Lead C: Inside Tamil Nadu + follow-up date in the future (Valid only, not Priority).
   - Lead D: Inside Tamil Nadu + no follow-up date (Valid only, not Priority).
   - Lead E: Out-of-state / unassigned branch (Unassigned only).
3. Test querying each category:
   - Verify `category=priority` returns Leads A & B.
   - Verify `category=valid` returns Leads A, B, C & D.
   - Verify `category=unassigned` returns Lead E.
   - Verify stats counts match expected totals.
4. Clean up test leads.
5. Create `11-01-SUMMARY.md`, `11-02-SUMMARY.md`, and `11-VERIFICATION.md`.
