  <action>
    Refactor `src/app/api/branches/route.ts`:
    1. **GET handler:**
       - Read search parameters: `format = searchParams.get('format')`, `includeInactive = searchParams.get('includeInactive') === 'true'`.
       - Query database:
         ```typescript
         const branches = await prisma.branch.findMany({
           where: includeInactive ? {} : { isActive: true },
           orderBy: { name: 'asc' },
         });
         ```
       - If `format === 'names'`, return `NextResponse.json({ branches: branches.map(b => b.name) })`.
       - Otherwise, return `NextResponse.json({ branches, branchNames: branches.map(b => b.name) })` so callers expecting either format receive their data without errors.
    2. **POST handler:**
       - Verify authenticated session using `await getCurrentUser()`.
       - Enforce RBAC: user must have role `ADMIN` or `SUPERADMIN`. Return 403 Forbidden if not authorized.
       - Parse and sanitize JSON payload: `name`, `code`, `address`, `city`, `latitude`, `longitude`, `radiusKm`.
       - Validate: `name` and `code` must be non-empty strings.
       - Normalize `code` to uppercase (`code.trim().toUpperCase()`).
       - Check for uniqueness collisions on `name` or `code`. If exists, return 409 Conflict with a descriptive error.
       - Parse coordinates: ensure `latitude` and `longitude` are converted to valid `Float` numbers or `null`.
       - Create record via `prisma.branch.create(...)`.
       - Return 201 Created with `{ success: true, branch }`.
  </action>

  <action>
    Create `src/app/api/branches/[id]/route.ts`:
    1. **GET handler:**
       - Parse `id` parameter as integer.
       - Query `prisma.branch.findUnique({ where: { id } })`.
       - Return 404 if not found; otherwise return `{ branch }`.
    2. **PUT handler:**
       - Parse `id` parameter as integer.
       - Authenticate session via `getCurrentUser()`.
       - Verify branch exists.
       - Enforce RBAC: allow if user is `ADMIN` / `SUPERADMIN` OR assigned manager (`currentUser.assignedBranch === existingBranch.name`).
       - Parse and sanitize update fields (`name`, `code`, `address`, `city`, `latitude`, `longitude`, `radiusKm`, `isActive`).
       - If `name` or `code` changed, check for collision with another branch.
       - Update branch record via `prisma.branch.update(...)`.
       - Return 200 OK with `{ success: true, branch: updated }`.
    3. **DELETE handler (Soft-Delete):**
       - Parse `id` parameter as integer.
       - Authenticate session (require `ADMIN` / `SUPERADMIN`).
       - Perform soft-delete by setting `isActive: false` via `prisma.branch.update({ where: { id }, data: { isActive: false } })`.
       - Return 200 OK with `{ success: true, message: 'Branch deactivated' }`.
  </action>
