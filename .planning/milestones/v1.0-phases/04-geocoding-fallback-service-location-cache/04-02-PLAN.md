<task type="auto">
  <name>Task 1: Build Rate-Limited External Geocoder & Tiered Resolver</name>
  <files>src/lib/location/geocoder.ts</files>
  <read_first>src/lib/location/matcher.ts, src/lib/location/types.ts, src/lib/prisma.ts</read_first>
  <action>
    Create `src/lib/location/geocoder.ts`:
    1. Implement `RateLimiter` class:
       - Serial execution queue maintaining `minIntervalMs` (default 1000ms).
       - Throttles network invocations so external geocode calls never violate OSM policy or burst Google quotas.
    2. Implement external geocoding providers:
       - `queryNominatim(query: string)`: Calls `https://nominatim.openstreetmap.org/search` with `format=json&countrycodes=in&limit=1`, parsing `lat`, `lon`, `display_name`, and address components (`state`, `county`). Requires `User-Agent: SGA-Tata-CRM/1.0`.
       - `queryGoogle(query: string, apiKey: string)`: Calls Google Geocoding API if key provided.
    3. Implement `resolveLocationTiered(rawQuery: string)`:
       - Step 1: Run local dictionary matcher `resolveLocation(rawQuery)`. If matched, return immediately with `source: 'dictionary'` (<0.1ms).
       - Step 2: Normalize search term and check PostgreSQL `prisma.locationCache.findUnique({ where: { searchTerm } })`. If found, return cached record with `source: 'cache'`.
       - Step 3: Enqueue external geocode request via `RateLimiter`.
       - Step 4: If external call resolves coordinates:
         - Determine if location is within Tamil Nadu or Puducherry (via address `state` field).
         - Persist result into `prisma.locationCache.upsert(...)`.
         - Return resolved result with `source: 'geocoder'`.
       - Step 5: If external call fails or yields no results, return unassigned out-of-state / unknown result.
  </action>
  <verify>npx tsc --noEmit</verify>
  <acceptance_criteria>
    - `src/lib/location/geocoder.ts` exports `RateLimiter`, `resolveLocationTiered`, and `geocodeExternal`
    - Implements tiered cascade: dictionary -> cache -> external API
    - Persists resolved locations to `prisma.locationCache`
    - `npx tsc --noEmit` exits with code 0
  </acceptance_criteria>
