  <action>
    Create `src/lib/location/matcher.ts`:
    1. Implement helper functions:
       - `normalizeString(input: string): string`: lowercases, strips special characters/punctuation, removes noise words (district, dist, city, town, post, po, dt, taluk, tk, near, opp, opposite).
       - `extractPincode(input: string): string | null`: regex for 6-digit number starting with `60` to `64` (`/\b(6[0-4]\d{4})\b/`).
       - `damerauLevenshtein(a: string, b: string): number`: fast, bounded edit-distance with character transposition support.
       - `calculateSimilarity(a: string, b: string, distance: number): number`.
    2. Build main resolution function:
       ```typescript
       export function resolveLocation(
         rawQuery: string,
         options?: MatcherOptions
       ): LocationMatchResult
       ```
    3. Multi-tier resolution cascade:
       - **Stage 1 (Pincode):** If query contains valid TN postal code, lookup in `PINCODE_INDEX`. If found, return `matchType: 'pincode'`, confidence `1.0`.
       - **Stage 2 (Exact Canonical & Alias):** Check normalized query in `EXACT_INDEX` (confidence `1.0`) and `ALIAS_INDEX` (confidence `0.98`).
       - **Stage 3 (Token / Substring):** Split query into word tokens. Check if any individual word matches `EXACT_INDEX` or `ALIAS_INDEX`.
       - **Stage 4 (Fuzzy Edit Distance):** Scan candidate names within length difference $\le 2$. Compute Damerau-Levenshtein distance. If similarity $\ge$ `options.minConfidence ?? 0.75`, select highest score with `matchType: 'fuzzy'`.
       - **Stage 5 (Fallback):** If no candidate exceeds threshold, return `{ matched: false, matchType: 'none', confidence: 0 }`.
  </action>
