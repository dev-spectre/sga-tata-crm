Update Google Sheets sync engine (`src/lib/sync.ts`) to remove branch column dependency, automatically assign incoming leads to the nearest active branch based on city/location/zipcode, protect existing manual branch assignments from being overwritten, and audit routing decisions in `LeadActivity`.
</objective>

<task type="auto">
  <name>Task 1: Integrate Nearest-Branch Routing into Sheet Sync</name>
  <files>src/lib/sync.ts</files>
  <read_first>src/lib/sync.ts, src/lib/location/routing.ts</read_first>
  <action>
    Modify `src/lib/sync.ts`:
    1. Import `routeLeadToBranch`, `logRoutingActivity`, and `BranchCandidate` from `@/lib/location/routing`.
    2. Before processing sheet rows, pre-fetch all active branches:
       ```ts
       const activeBranches: BranchCandidate[] = await prisma.branch.findMany({
         where: { isActive: true },
         select: { id: true, name: true, code: true, city: true, latitude: true, longitude: true, radiusKm: true, isActive: true },
       });
       ```
    3. For each row being prepared for creation (`toCreate`):
       - If `!branch && city`:
         - Call `const routing = await routeLeadToBranch(city, { candidateBranches: activeBranches })`.
         - If `routing.status === 'assigned'` and `routing.assignedBranch`:
           - Set `branch = routing.assignedBranch.name`.
           - Track routing result alongside lead fingerprint so audit activity can be logged after insertion.
    4. For existing lead reconciliation:
       - If incoming `branch` is empty string:
         - Keep `existing.branch`! `const finalBranch = branch || existing.branch;`
         - In `hasMetadataChanged`, do not consider `branch` changed if incoming `branch` is empty and `existing.branch` is non-empty.
         - If `!existing.branch && city`:
           - Attempt auto-routing to populate missing branch on the existing lead:
           - Call `await routeLeadToBranch(city, { candidateBranches: activeBranches })`.
           - If resolved, update `existing.branch`.
    5. After `prisma.lead.createMany`:
       - Query newly created leads matching fingerprints of auto-routed leads.
       - Log routing activities via `logRoutingActivity(lead.id, routing)`.
  </action>
