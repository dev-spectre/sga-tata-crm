  <action>
    Edit `prisma/schema.prisma` to append the `Branch` model:
    ```prisma
    model Branch {
      id        Int      @id @default(autoincrement())
      name      String   @unique
      code      String   @unique
      address   String   @default("")
      city      String   @default("")
      latitude  Float?
      longitude Float?
      radiusKm  Float    @default(50.0)
      isActive  Boolean  @default(true)
      createdAt DateTime @default(now())
      updatedAt DateTime @updatedAt

      @@index([name])
      @@index([code])
      @@index([city])
      @@index([isActive])
    }
    ```
    Ensure `@unique` is present on both `name` and `code` as agreed in Decision D-05.
    Ensure `isActive` defaults to `true` as agreed in Decision D-03.
  </action>
