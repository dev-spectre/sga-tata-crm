<task type="auto">
  <name>Task 1: Build Branch Create and Edit Modal Component</name>
  <files>src/app/branches/BranchModal.tsx</files>
  <read_first>src/app/accounts/page.tsx, src/app/globals.css</read_first>
  <action>
    Create `src/app/branches/BranchModal.tsx`:
    1. Accept props:
       - `isOpen: boolean`
       - `onClose: () => void`
       - `onSaved: (savedBranch: any) => void`
       - `initialData?: Branch | null` (null for Create, populated for Edit)
    2. Manage form states:
       - `name: string` (required)
       - `code: string` (required, auto-convert to uppercase)
       - `city: string`
       - `address: string`
       - `latitude: string`
       - `longitude: string`
       - `radiusKm: string` (defaults to "50")
       - `isActive: boolean` (defaults to true)
       - `loading: boolean`
       - `error: string | null`
       - `geoLoading: boolean`
    3. Implement browser geolocation helper:
       - Function `handleGetCurrentLocation`: calls `navigator.geolocation.getCurrentPosition` if available, populates `latitude` and `longitude` to 6 decimal places, or displays a brief warning if permission was denied.
    4. Form validation on submit:
       - Ensure `name` and `code` are non-empty.
       - If `latitude` provided, ensure it is a valid number between -90 and 90.
       - If `longitude` provided, ensure it is a valid number between -180 and 180.
       - Ensure `radiusKm` is a positive number.
    5. Submit to backend:
       - If `initialData` exists (Edit mode): `PUT /api/branches/${initialData.id}`
       - If no `initialData` (Create mode): `POST /api/branches`
       - Handle 409 Conflict gracefully: set `error` state with backend error message (e.g. "Branch code already exists").
       - On success: call `onSaved(data.branch)` and close modal.
  </action>

    - API 409 errors are displayed inline
    - `npx tsc --noEmit` exits with code 0
  </acceptance_criteria>
