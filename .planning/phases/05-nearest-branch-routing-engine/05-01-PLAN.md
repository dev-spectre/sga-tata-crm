  <action>
    Create `src/lib/location/routing.ts`:
    1. Define interfaces:
       - `BranchCandidate`: `{ id: number; name: string; code: string; city: string; latitude: number; longitude: number; radiusKm?: number | null; isActive: boolean; }`
       - `BranchDistance`: `BranchCandidate & { distanceKm: number }`
       - `RoutingResult`:
         ```ts
         export interface RoutingResult {
           assignedBranch: BranchCandidate | null;
           distanceKm: number | null;
           allBranchesRanked?: BranchDistance[];
           resolvedLocation: {
             query: string;
             canonicalName: string;
             district: string;
             state: string;
             latitude: number;
             longitude: number;
             source: string;
           } | null;
           isOutOfState: boolean;
           isUnresolved: boolean;
           status: 'assigned' | 'out_of_state' | 'unresolved' | 'no_active_branches';
           reason: string;
         }
         ```
    2. Implement `calculateHaversineDistance(lat1, lon1, lat2, lon2): number`:
       - Calculate spherical distance in kilometers using earth radius $R = 6371$.
       - Return rounded to 2 decimal places.
    3. Implement `findNearestBranch(leadLat, leadLon, branches?: BranchCandidate[]): { nearestBranch: BranchCandidate | null; distanceKm: number | null; ranked: BranchDistance[] }`:
       - If `branches` not supplied, fetch active branches from `prisma.branch.findMany({ where: { isActive: true } })`.
       - Filter out branches with missing coordinates (0, 0 or null).
       - Calculate Haversine distance to each branch, sort ascending by distance.
       - Return the branch with minimum distance.
    4. Implement `routeLeadToBranch(locationQuery: string, options?: { branches?: BranchCandidate[]; skipExternalGeocode?: boolean }): Promise<RoutingResult>`:
       - Step 1: Call `resolveLocationTiered(locationQuery, { skipExternal: options?.skipExternalGeocode })`.
       - Step 2: If `!locationResult.matched`, return status `'unresolved'` with `assignedBranch: null`.
       - Step 3: If `!locationResult.isTamilNadu`, return status `'out_of_state'` with `assignedBranch: null`, `isOutOfState: true`.
       - Step 4: Call `findNearestBranch(locationResult.latitude, locationResult.longitude, options?.branches)`.
       - Step 5: Return status `'assigned'` with `assignedBranch`, `distanceKm`, and `resolvedLocation`.
  </action>
